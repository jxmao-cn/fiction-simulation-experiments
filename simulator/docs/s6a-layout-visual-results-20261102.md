## 映射与一致性核对

解析资产实际Gmsh node tag并建立tag→局部节点映射，四面体6851个、表面三角形2474个。各体节点范围连续，分别为7040和28160个总节点；每体1760节点，body_id覆盖0–3和0–15。四面体和表面均按各体节点偏移映射，检查其索引范围不越过对象边界。

从每个节点的global与local坐标差核对逐体平移恒定，再核对global位置减disp等于资产参考坐标加该平移。两个场景初态重建的最大分量误差均为1.73472347598e-18 m。得到的平移集合分别与1.5 m间距的2×2和4×4网格完全吻合；没有以全局bbox中心代替逐体变换。保存末态全部有限。

`state.csv`本身不含单元拓扑；渲染和映射使用已冻结资产的tet/surface索引与运行采用的连续逐体节点区间，并未声称从末态文件独立推导网格连接。原始数值验收仍以对应run报告为准。
