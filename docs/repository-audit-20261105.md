## 主工程发现与修复

1. **未收敛也返回成功**：原 `ipc_mesh_demo` 忽略 `StepReport.converged`，最后只检查坐标/速度有限性。基线用 `--steps 1 --max-iter 0` 可出现 `stop_reason=maxIter` 却打印 `[PASS]` 并返回 0。现在遇到未收敛或非有限状态立即报告失败步骤、原因和残差，返回非零；另以正常正整数迭代上限的真实未收敛场景做回归。
2. **非法数值参数被接受**：`std::stod` 接受 NaN/Inf，`long` 未检查上界就转换为 `int`，例如 `--steps 4294967296` 在本机变成零步。现在拒绝非有限浮点与超出 `int` 范围的整数，并检查必要的正值参数。
3. **样例材质标题错误**：原控制台即便选择 NH 仍称 mass-spring；修正为根据实际材质显示。
4. **查看器与控制台初始条件不一致**：查看器忽略 `--init-vel`，且首次驱动边界目标时间为 0 而非 dt。同步这两处行为，并对求解失败停止推进。
5. **输出失败未传播**：原样例忽略 OBJ writer 的返回值，目录可创建但文件无法写入时仍宣称成功。输出错误应报告并返回非零。缺少 ffmpeg 时保留已写出的帧仍是明确的可选功能回退，不宣称 MP4 已生成。

新增 CLI 回归检查和两种后端的 GitHub Actions 构建/测试配置，避免只覆盖正常小样例而漏掉错误路径。
