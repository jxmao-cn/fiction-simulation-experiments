# S3 时间/空间离散对比：M2/M3/M4 × dt 阶梯（执行规格）

## 1. 目标

固定物理问题（M2/M3/M4 同一方杆、同一材料、同一重力阶跃、同一固定端），分别做 dt 阶梯，回答两个问题：

1. **时间收敛**：固定每张网格，尖端位移轨迹是否随 dt 减小而更接近更细 dt 的结果；观测阶数是否与隐式欧拉的一阶行为相容。
2. **空间敏感性**：同一 dt 下 M2/M3/M4 的轨迹差异，确认 M2 的空间过刚不是时间步造成的；本批不把 M3/M4 当作连续体真值。

窗口 0–0.5 s，覆盖原 S3 首次峰值（约 0.190 s）及回落。物理时间 0.5 s 是局部窗口，不外推到 10 s。

## 2. 固定配置

- 几何：`M2.msh`（525 节点/1920 tet）、`M3.msh`（3321/15360）、`M4.msh`（10309/51840），均为 1 m × 0.05 m × 0.05 m 方杆。
- 材料：NH，E=4.40e7 Pa，nu=0.3，rho=1000；总质量 2.5 kg。
- 边界：x=0 全端面固定，x=1 端面观测；参考形状、零初速。
- 载荷：重力 (0,0,-9.81)，t=0 阶跃。
- 时间积分：隐式欧拉，step 判据，tol=1e-6，maxIter=50，DBC 初始 k=1e8。
- 每病例独立从参考形状开始，不接续其他 dt 的末态。

## 4. 主指标与判定

主量：x=1 端面 25 个节点的算术平均向下 z 位移 `u(t)`。统一在 t=0,0.005,...,0.5 s 的 101 个公共时刻比较，不插值、不做相位对齐。

- 固定网格的相邻 dt 差：
  - `e1 = max_t |u_0.005(t) - u_0.0025(t)|`
  - `e2 = max_t |u_0.0025(t) - u_0.00125(t)|`
  - 时间收敛的必要条件：`e2 < e1`；同时报告 RMS 与观测阶数 `p = log2(e1/e2)`（仅诊断，不单独作为通过门槛）。
- 同 dt 的网格差：报告 M2/M3/M4 两两最大差与 RMS，用于确认空间离散影响；不把最小差当成精度通过。
- 安全/求解门槛：每步 `converged=1`、状态有限、min J>0.3、DBC 误差<1e-6 m；任一失败即停止该病例，保留现场，不调参重跑。
- 若 `e2 >= e1`，该网格记为“时间误差未单调下降”，不通过本批；不追加更细 dt 追绿，另立批次分析。
